# PlotInjector 剧情注入器

个人自用的 SillyTavern 酒馆助手脚本，不提供支持，不接受需求与问题反馈。

当前版本：v0.1.7

## 功能

- 一条 if 线是一个「项目」，按 讨论 → 设定 → 大纲 → 执行 四个页签推进
- 讨论：与 AI 多轮讨论剧情，可附带世界书条目、当前设定和大纲作参考；长讨论自动折叠成摘要，可导出后清空
- 设定：AI 按内置写作基准整理世界观正文，新旧稿按分块对比采用，保留最近 10 个历史版本
- 大纲：剧情 YAML（卷 → 阶段 → 节点）导入、编辑、导出；AI 一次写一卷，格式错误时指出行号并可让 AI 修正
- 执行：设定和当前阶段详细以常驻虚拟世界书条目注入，位置、深度、角色、顺序规则与世界书一致；详细条目注明是尚未发生的剧情规划
- 推进：每 N 楼由进度检测模型对照剧情索引（只给检测用，不注入正文）判断节点是否发生；可选询问、自动推进、只勾节点
- 偏离：检测发现剧情严重偏离大纲时提醒或自动改写后续阶段，改写可撤销
- 一张角色卡同时启用一个项目，进度随聊天保存
- 数据全部存在酒馆本地 `user/files/pi-*`，浏览器只记界面状态；数据管理页可单删、清理孤立文件、全部清除（先下载备份），世界书管理页直接修改角色卡世界书：条目开关、删除、编辑位置与关键词和内容，TavernDB-ACU 数据库条目按字段折叠开关

## 安装

在酒馆助手中导入 `loader/plot-injector.json`，点击 QR 栏的「剧情注入」按钮打开。

加载器启动时读取本仓库最新的版本标签（缓存 30 分钟），无需重复导入。设置页可锁定某个版本标签，或填 `main` 使用最新提交。

不联网更新时可导入 `dist/plot-injector-standalone.json`（内嵌完整程序）。

## 要求

- SillyTavern 1.13 以上（需要 `SillyTavern.libs.yaml` 与世界书条目加载事件；没有该事件时退回为专用世界书）
- 酒馆助手（JS-Slash-Runner）

## 开发

```text
npm install
npm test        # 核心逻辑 + 发布文件冒烟测试
npm run build   # 生成 dist/ 与 loader/plot-injector.json
```

### v0.1.12

- 加载器：「指定版本」填错（版本不存在或只填了半截）时自动改用最新版本并提示，不再打不开。**需要重新导入一次 `loader/plot-injector.json`**。

### v0.1.11

- 修复执行页有时打开一片空白：酒馆刚加载、插件数据还没读完时打开面板，读完后不会自动回到本卡的当前项目，手机上项目列表又收在抽屉里，看起来就是空的。现在读完后自动打开。
- 项目文件读取失败时显示原因和「重试」，不再一直显示「正在读取项目」；读取最多等 20 秒。
- 某一页显示出错时显示错误原因和「重试」，并记进诊断页，不再留空白；界面出错也不会打断后台检测。
- 性能：修改设定、大纲时侧栏和顶栏内容不变就不再重建；世界书 token 按条缓存，开关或编辑一条只重算那一条，第一次统计时分批请求。
- 注入位置：设定和阶段详细默认都放在「角色定义前」；在执行页改位置、深度、顺序对本项目所有阶段生效，打开下一段不用再改。旧项目没改过的默认位置自动换成新默认。
- 界面改为色块区分：按钮、输入框、条目去掉描边，用浅灰色块；主按钮统一为深色，强调色只标选中和进行中；按钮组铺满整行；卡片标题加大。
- 执行页阶段改为时间线：粗环表示阶段，已过实心、进行中亮色、之后虚线连接；手动改状态、设为当前收进每行的「⋯」。
- 世界书工具栏改为一行小色块按钮，重命名、另存副本、导出、删除等收进「更多」。
- 设置移到顶栏右上角的齿轮，新项目移到侧栏顶部。

### v0.1.10

- 世界书管理改为图标工具栏。页面顶部：新建世界书、导入（酒馆导出的世界书 json）、打开其他（未绑定当前卡的世界书）。每本书：新建条目、批量选择、修复标点、正则替换、重命名、另存副本、导出、删除本书。
- 重命名会同时改聊天、角色卡和全局里的绑定；有绑定改不过去时保留旧书并提示。删除本书前下载整本备份，并解除这些绑定。
- 条目编辑新增标题；每条可一键复制。
- 批量选择工具栏：全选、迁移、顺序重排、正则替换、开启、关闭、删除。
- 设置页「推进速度说明」并入「阶段推进」，平时只占一行。

### v0.1.9

- 设置页「推进速度说明」改为单独一张卡片，默认收起；展开后用下拉框选择要编辑的档位（标出当前聊天使用的档），并注明速度在执行页选择，不再像速度选择器。
- 诊断页：刚打开聊天、还没发过消息时不再误报「没收到回复事件」。

- 世界书管理新增「正则替换」：可按正则或原文查找，范围可选内容、标题、关键词，先预览匹配条数，替换前下载备份。进入批量选择并勾选条目时只替换选中的条目。
- 世界书管理新增「批量选择」：勾选手写条目后可「迁移到其他世界书」（复制或移动，可新建世界书，移动前下载备份）和「顺序重排」（填起始数字和间隔，按列表先后或原有顺序值重新编号）。

### v0.1.7

- 设定页：分块标签可直接删除整个分块；补定增加「丢弃」。
- 清空讨论改为输入框左侧的按钮。
