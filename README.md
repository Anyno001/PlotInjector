# PlotInjector 剧情注入器

个人自用的 SillyTavern 酒馆助手脚本，不提供支持，不接受需求与问题反馈。

当前版本：v0.1.20

## 功能

- 一条 if 线是一个「项目」，按 讨论 → 设定 → 大纲 → 执行 四个页签推进
- 讨论：与 AI 多轮讨论剧情，可附带世界书条目、当前设定和大纲作参考；长讨论自动折叠成摘要，可导出后清空
- 设定：AI 按内置写作基准整理世界观正文，新旧稿按分块对比采用，保留最近 10 个历史版本
- 大纲：剧情 YAML（卷 → 阶段 → 节点）导入、编辑、导出；AI 一次写一卷，格式错误时指出行号并可让 AI 修正
- 执行：设定和当前阶段详细以常驻虚拟世界书条目注入，位置、深度、角色、顺序规则与世界书一致；详细条目注明是尚未发生的剧情规划
- 推进：每 N 楼由进度检测模型对照剧情索引（只给检测用，不注入正文）判断节点是否发生；可选询问、自动推进、只勾节点
- 偏离：检测发现剧情严重偏离大纲时提醒或自动改写后续阶段，改写可撤销
- 一张角色卡同时启用一个项目，进度随聊天保存
- 数据全部存在酒馆本地 `user/files/pi-*`，浏览器只记界面状态；数据管理页可单删、清理孤立文件、全部清除（先下载备份），世界书管理页直接修改角色卡世界书：条目开关、删除、编辑位置与关键词和内容，TavernDB-ACU 数据库条目按字段折叠开关

## 安装

在酒馆助手中导入 `loader/plot-injector.json`，点击 QR 栏的「剧情注入」按钮打开。

加载器启动时读取本仓库最新的版本标签（缓存 30 分钟），无需重复导入。设置页可锁定某个版本标签，或填 `main` 使用最新提交。

不联网更新时可导入 `dist/plot-injector-standalone.json`（内嵌完整程序）。

## 要求

- SillyTavern 1.13 以上（需要 `SillyTavern.libs.yaml` 与世界书条目加载事件；没有该事件时退回为专用世界书）
- 酒馆助手（JS-Slash-Runner）

## 开发

```text
npm install
npm test        # 核心逻辑 + 发布文件冒烟测试
npm run build   # 生成 dist/ 与 loader/plot-injector.json
```
