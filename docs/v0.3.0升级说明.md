# v0.3.0 升级说明

本版新增统一的导入审阅和已有剧情线修改流程，保留原有大纲推进、线索推进、人设、无限流与世界书工具。

## 安装与更新

- 自动更新加载器：未指定旧版本时会跟随最新版本标签；标签查询缓存最多 30 分钟。需要立即更新时，可在「数据管理 → 版本更新」指定 `v0.3.0` 后刷新，或重新导入仓库中的 `loader/plot-injector.json`。
- 明确锁定旧标签的用户继续使用指定版本；清空指定版本即可跟随最新版本。
- 单文件版：重新导入 `dist/plot-injector-standalone.json`。脚本 ID 沿用原版，避免同时启用重复实例。
- 升级前可在数据管理导出备份，并备份聊天。项目和进度仍保存在原来的位置，不需要重新建项目或重做表格。

## 已有数据如何继续使用

旧项目未提供保密名单时，仍按未提供处理；不会自动新增一份名单或更改推进模式。

旧的逐线导入审阅任务打开后会转入统一审阅页，沿用已经改过的草稿、意见、不导入选择和已采用状态。旧记录保留在任务中，后续修改使用新审阅会话；没有必要删除旧任务再导入。

并发整理中途失败，只需继续未成功的批次。已保存任务中缺少的批次位置也可以读取，不会因此丢掉后面已完成的结果。

更早版本的配置、节点编号和数据库迁移方式见 [v0.2.0 升级说明](v0.2.0升级说明.md)。

## 操作上的变化

- 导入和已有大纲的「审阅修改」使用同一套页面。按页写意见、发送给 AI、确认草稿、保存到大纲；AI 回复不会直接覆盖正式大纲。
- 大纲页直接编辑字段会自动保存；审阅页里的草稿仍需要点「保存到大纲」。
- 多条支线跨段整理时，已有内容优先，补入新增内容，并按线汇总提示；单条导入仍逐项列出冲突。
- 讨论区的剧情修改改用「审阅修改」，旧的提案模块和逐条审阅页面已移除。

普通线索回合仍读取现有表格，不因这次升级增加模型请求。导入、发送修改意见等操作才调用配置的模型。

自动检查与模拟宿主测试不能保证所有模型的输出和实际填表都正确；执行页正文、填表联动及手机软键盘仍需结合实际酒馆环境验证。
